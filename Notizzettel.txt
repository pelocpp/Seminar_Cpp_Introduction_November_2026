Wie werden C++ Programme erstellt und wie laufen sie ab?

a) Editor (Nicht: Word; Texteditor)

   ==> Quelltext eingeben.

b) Programmiersprache: natürliche Sprache:

   Lexikon (Wörter)
   Grammatik (Satz korrekt)

   Beispiel:

    #include <iostream>

	void main()
	{
		std::cout << "Hallo Seminar";
	}

	Wörter:  void  main  { 123 ;  << :: 

	Grammatik: 

	Wie kann man die Grammatik überprüfen:  SW-Tool ( Compiler / Übersetzer )

	Menü "Kompilieren"


c) Ein lauffähiges Programm erzeugen.

   Maschinencode // CPU 

   Menü "Erstellen"

   Wer macht das ?

   2 Schritte:

   i) Zu jeder Datei wird vom Compiler ein "quasi" Kompilat erstellt: 

               Vorbereitetes Maschinenprogramm.

			   Windows: .obj,  Linux:  .o

			   Standardisiertes Format:  
			      Common Object File Format (COFF; deutsch „allgemeines Objektdateiformat“) 

	ii) Zweites Tool: Linker

	    == hat alle .obj Dateien als Eingabe
		== hat eine Datei (Windows: .exe, Linux: ohne Erweiterung) als Ausgabe

d) Programm ausführen

   Klick auf eine .exe Datei // executable

Es gibt statische und dynamische Bibliotheken:

a) Man schreibt ein C++ Programm.

b) Dieses möchte eine Bibliothek verwenden.

   Hier gibt es zwei Möglichkeiten:

   i) Die Bibliothek wird - durch den Linker - in das .exe File 
      mit eingebunden.

	  => .exe ( Bibliothek im Bauch )

	  Bibliothek ist Teil von dem .exe File

	  Damit kann sie woanders so nicht verwendet werden.

  ii) Die Bibliothek liegt - nach der Erstellung - in einem Verzeichnis auf der Festplatte

      Sie kann - unter der Angabe des Pfads - durch ein anderes Programm
	  geladen werden.  // Win32:   LoadLibrary

	  Dann hat man den Zugriff auf Funktionen ( C - Funktionen ) in dieser Bibliothek.

Beobachtung:

Visual Code:  

   C++ Programm ========>  Makefile

Wer führt ein makefile aus:   Tool  : nmake / make / Cmake

Ein Makefile ist eine Gebrauchsanweisung
für ein C++-Projekt, das aus einer oder mehreren Quelldateien (main.cpp) besteht.

Es kompiliert das Programm, unterstützt sauberes Aufräumen und ist leicht erweiterbar.

Und es wird das Maschinenprogramm (.exe, .so) erstellt.

===================================================

Einbinden einer DLL:

a) Die Dll muss auf irgend eine Weise dem Programm zugeordnet werden:

   - zur Laufzeit: LoadLibrary (Win32)

   - zur Übersetzungszeit: Im Makefile

b) Bzgl. C: Ein Header-File

   Hier wird die Schnittstelle der Funktion beschrieben (Parameter, Rückgabewert).

c) Der Linker oder zur Laufzeit (LoadLibrary) müssen das .so
   laden.

void Time::setSeconds(int seconds)
{
	if (s >= 0 && s < 60)
	{
		seconds = s;
	}
	else
	{
		std::cout << "Falscher Sekundenwert: " << s << std::endl;
	}
}
